[부탁드릴 내용]
브이월드(vworld.kr) 사이트에서 "공동주택가격" 데이터의 API 코드를 찾아서
캡처(스크린샷) 또는 복사해서 보내주시면 됩니다. 아래 순서대로만 해주시면 돼요.

1. vworld.kr 접속 → 로그인
2. 상단 메뉴에서 "오픈API" (또는 "Open API") 클릭
3. "데이터 API" 또는 "API 가이드" 항목으로 이동
4. 검색창이나 목록에서 "공동주택가격" 검색
5. 검색 결과 화면을 그대로 캡처해서 보내주세요.
   - 특히 "데이터명", "data=" 로 시작하는 코드, 또는 예제 요청 URL이 보이면
     그 부분이 제일 중요합니다.
   - 여러 개 나오면(예: "공동주택가격(속성)", "공동주택가격(공간)" 등) 전부 캡처해주세요.

[참고 - 못 찾으시는 경우]
"공동주택가격"으로 안 나오면 아래 단어로도 검색해봐주세요:
- "주택가격"
- "부동산가격"
- "공시가격"

[하나 더 확인 부탁]
혹시 마이페이지 > 인증키 신청현황(또는 활용신청 내역)에 들어가시면, 처음 키 발급받을 때
선택했던 API 상품 목록이 남아있을 수 있어요. 거기도 한 번 봐주시면 도움이 될 것 같습니다.
